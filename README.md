## Project Description
This project is a calculator application built in Android Studio using Java.

The application supports basic arithmetic operations:
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## Features Implemented
1. Basic calculator UI using ConstraintLayout and GridLayout.
2. Arithmetic operations between two operands.
3. Division by zero handling shows "Cannot divide by zero".
4. State preservation using onSaveInstanceState to keep the display value when the screen rotates.
5. Custom operator based on my Student ID.

## Custom Operator
My student ID is 22103894 and it ends in 894, so the custom operator multiplies the current display value by 8.94.

Example:
10 × 8.94 = 89.40
